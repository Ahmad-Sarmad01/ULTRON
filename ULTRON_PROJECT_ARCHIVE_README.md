# ULTRON project archive

This archive combines the most recent full ULTRON source archive available in this conversation with the later access-gate/mode-selection project snapshot and the developer footer component/link discussed in chat.

## Included
- React + Vite frontend source and lockfile
- FastAPI backend source and database files present in the source archive
- Chat, English/Urdu voice, TTS, memory/recall, missions/reminders, System Scan, Vision, personality modes, ULTRON Mode and hand-gesture source
- Access/login gate and interface mode selection
- Developer footer and Ahmad LinkedIn link
- Project configuration and public assets

## Setup
1. Install Node.js LTS.
2. In the `Ultron/ultron` project directory, run `npm install` and then `npm run dev`.
3. Set up the Python backend using the project's dependency file and your own environment configuration.
4. Keep private API keys in your local `.env`; do not publish secrets.

Dependencies, virtual environments, build output, caches, and compiled Python bytecode were omitted to keep the archive portable. Install dependencies on the target machine.
